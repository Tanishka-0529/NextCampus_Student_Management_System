# 🎓 NextCampus — Student Management System

A simple, responsive full-stack web application to manage student records. Built with Python Flask, SQLite, HTML, CSS, and JavaScript.

---

## ✨ Features

- **Add, Edit & Delete Students:** Full CRUD management with input validation.
- **Search & Filter:** Find students by Name, Roll Number, or Department (ECS, ME, CS).
- **Dashboard Overview:** Displays live statistics for total students, class average, and top scorer.
- **Responsive Design:** Works smoothly on mobile, tablet, and desktop views.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
- **Backend:** Python (Flask)
- **Database:** SQLite3
